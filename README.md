# Sanvi Mantri — NEET 2028 Unit Test 3

A personalised, browser-based NEET practice examination designed by the **Scrutiny Academy Team**.

## Test blueprint

- **Physics — 45 MCQs:** Laws of Motion (friction through the end) and Work, Energy & Power (through Power)
- **Chemistry — 45 MCQs:** Thermodynamics
- **Botany — 45 MCQs:** Fabaceae, Solanaceae and Liliaceae; complete Anatomy of Flowering Plants
- **Zoology — 45 MCQs:** Structural Organisation in Animals — Frog only
- **Duration:** 3 hours
- **Maximum marks:** 720
- **Marking:** +4 correct, −1 incorrect, 0 unattempted

## Included features

- One-attempt browser lock with a persistent 3-hour timer
- Auto-save, section navigation, question palette and mark-for-review
- Early submission and automatic submission at time expiry
- Personalised result celebration with confetti and motivational feedback
- Scoreboard, subject analysis, accuracy and time-used metrics
- Complete question-by-question review
- Downloadable incorrect-MCQ revision list
- Direct WhatsApp result sharing to Scrutiny Academy
- Responsive doctor-themed design for phone, tablet and desktop
- Properly rendered table and diagram-based questions
